# Demo video script (target 4 minutes, hard limit 5)

Record one clean take after running `docs/E2E-CHECKLIST.md`. Say what is simulated out loud; judges reward honesty.

| Time | Screen | Say |
|---|---|---|
| 0:00 | Landing page, 3D colony turning | "Floods hit neighbourhoods first, yet ordinary people rarely get clear risk information, and community climate work is hard to trust. EcoShield AI fixes both." |
| 0:20 | Log in as Citizen, dashboard | "Here is real rainfall data for Faisalabad from Open-Meteo, with its source and time. Our indicator is a simple, transparent rule, not a flood model." |
| 0:45 | AI Assistant | "The AI explains the outlook in plain language and gives a checklist. It is advisory only." |
| 1:05 | 3D Map: click building, layer, water slider | "This colony is a simulation, clearly labelled. Raise the water and low-lying homes are affected first. It shows how preparedness could be explored; it is not a prediction." |
| 1:40 | New report with photo | "A citizen reports a blocked drain. The photo gets a SHA-256 fingerprint right away." |
| 2:05 | Report page: Analyse | "The AI summarises the report and points out missing details. It cannot approve anything." |
| 2:20 | Second report, same photo | "Submitting the same photo again triggers a duplicate warning. It is a warning for the reviewer, not an accusation." |
| 2:40 | Log in as Reviewer, approve | "A human reviewer decides. Every action is in the audit history." |
| 3:00 | Register on blockchain, Etherscan | "Approval registers only hashes on the Sepolia testnet: no photo, no personal data. This is the real transaction." |
| 3:25 | Public page in a private window | "Anyone can open this link without an account. It re-checks the chain and shows Verified." |
| 3:45 | Upload original vs a different photo | "The original matches; a different file does not. Verification happens in the browser." |
| 4:05 | Close on landing | "A blockchain record shows evidence was unchanged after approval. Human review decides if it is true. Know the risk, protect what matters, prove the impact." |

Tips: zoom the browser to 110%; hide bookmarks and notifications; keep the 3D part short; if the transaction is slow, cut the waiting in editing but mention that it takes about a minute.
